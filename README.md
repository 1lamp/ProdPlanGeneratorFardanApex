# ProdPlanGeneratorFardanApex

## اتصال به ERP و ثبت وضعیت برگه تولید

اطلاعات سفارش و اقلام مستقیماً از SQL Server فاردان دریافت می‌شود؛ فایل orders.xlsx و جست‌وجوی PDF قدیمی سفارش دیگر استفاده نمی‌شوند.

مقادیر sql_server، sql_database و در صورت نیاز sql_driver را در config.json محلی تنظیم کنید. اعتبارنامه‌ها باید بیرون از مخزن بمانند:
- FARDAN_SQL_SERVER
- FARDAN_SQL_DATABASE (اختیاری، پیش‌فرض FARDAN_OLTP)
- FARDAN_SQL_USERNAME (در صورت حذف، احراز هویت یکپارچه ویندوز استفاده می‌شود)
- FARDAN_SQL_PASSWORD (فقط برای نام کاربری SQL)

وابستگی‌ها را از requirements.txt نصب کنید. برای تولید LOM، زمان‌سنجی، آماده‌سازی و برگه‌های شرطی، Excel و فایل اشتراکی Database.xlsm همچنان لازم است و workbook به‌صورت read-only باز می‌شود. برنامه برای ثبت وضعیت آماده‌شدن برگه تولید، علاوه بر SELECT به مجوز UPDATE فقط روی دو ستون sales.orders.production_sheet_prepared و sales.orders.production_sheet_prepared_at نیاز دارد. رمز را در config.json نگذارید.

## وضعیت برگه تولید

دو ستون production_sheet_prepared و production_sheet_prepared_at در جدول sales.orders وضعیت و زمان آخرین تولید موفق فایل نهایی را نگه می‌دارند. فهرست بروزرسانی فقط سفارش‌های فعال دارای سریال کامل را نشان می‌دهد که هنوز برگه تولیدشان آماده نشده است. ورود دستی شماره سفارش همچنان مجاز است؛ بنابراین سفارش‌های قبلاً آماده‌شده نیز در صورت واردکردن شماره، دوباره پردازش می‌شوند و در صورت ساخت موفق فایل نهایی، زمان ثبت‌شده به‌روزرسانی می‌شود.

برای دیتابیس موجود، اسکریپت migrations/20261024_add_production_sheet_status.sql را یک‌بار اجرا کنید. اسکریپت اصلی migrations/FardanOLTP.sql نیز برای نصب‌های جدید به‌روزرسانی شده است.

## محدودیت تاریخ ایجاد سریال

در شِمای فعلی FardanOLTP، ستون sales.order_details.created_at زمان ایجاد ردیف قلم سفارش است، نه زمان تخصیص سریال تولید. برنامه عمداً این دو را یکی فرض نمی‌کند. اگر یکی از ستون‌های production_serial_created_at یا serial_created_at در جدول order_details موجود باشد، از آن برای زمان تأیید سفارش استفاده می‌شود؛ در غیر این صورت تاریخ تأیید «نامشخص» نمایش داده می‌شود و مرتب‌سازی به تاریخ سفارش برمی‌گردد. برای تکمیل مرتب‌سازی دقیق بر اساس زمان تأیید، باید تغییر جداگانه‌ای در FardanERP انجام شود تا هنگام ثبت سریال، زمان آن ثبت شود. برای سریال‌های قدیمی نباید تاریخ ساختگی ایجاد کرد.
